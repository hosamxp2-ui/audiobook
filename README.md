# صوتي — المكتبة الصوتية الإسلامية (المرحلة الثانية)

واجهة عربية RTL متجاوبة مع البحث والتصنيفات والمفضلة والمظهر الداكن، إضافة إلى مكتبة صوتية محلية ومشغل وحفظ مواضع التشغيل والعلامات المرجعية وتقدّم الملف والمجموعة.

## الملفات
- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب.
- `app.js`: بيانات الكتب وواجهة المكتبة المحلية والمشغل والتقدّم والعلامات المرجعية.
- `manifest.json`: بيانات تثبيت PWA.
- `sw.js`: تخزين ملفات واجهة التطبيق فقط؛ لا يخزن ملفات الصوت في Cache API.
- `assets/icon.svg`: أيقونة التطبيق.

## النشر من الهاتف
1. أنشئ مستودع GitHub باسم `sawti-islamic-library` واجعله Public.
2. ارفع محتويات هذه الحزمة إلى جذر المستودع مباشرة، بحيث يظهر `index.html` بجانب `app.js` و`styles.css`، ويكون مجلد `assets` في الجذر.
3. افتح المستودع ثم Settings → Pages.
4. من Build and deployment اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)`، واضغط Save.
5. انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages. لا تفترض أن النشر اكتمل حتى يظهر رابط الموقع وحالة ناجحة.
6. افتح الرابط عبر HTTPS. جرّب البحث، والتصنيفات، والتفاصيل، والمفضلة، والمظهر الداكن.
7. لاختبار الواجهة دون اتصال: افتح الموقع مرة مع اتصال الإنترنت وانتظر تحميله، ثم فعّل وضع الطيران وأعد فتحه. قد يتطلب أول تسجيل Service Worker إعادة تحميل واحدة.

## ملاحظات فنية
- مسارات الملفات نسبية لتعمل على رابط مشروع GitHub Pages.
- أول تسجيل لـ Service Worker يحدث عند فتح الموقع عبر HTTPS أو localhost، وليس عند فتح الملف محليًا مباشرة.
- عند تحديث ملفات الواجهة، غيّر اسم التخزين المؤقت في `sw.js` عند كل تحديث جديد (مثل `sawti-shell-v3`) لإبطال التخزين المؤقت القديم.
- ## استخدام المكتبة الصوتية المحلية
1. افتح الموقع المنشور عبر HTTPS.
2. اضغط «اختيار مجلد صوتي». إذا دعم المتصفح واجهة اختيار المجلد، اختر المجلد واسمح بالقراءة. يحفظ التطبيق مراجع الملفات محليًا ويحاول استعادة الإذن لاحقًا؛ قد يطلب المتصفح الإذن مجددًا.
3. إذا لم يظهر اختيار المجلد أو لم يدعمه المتصفح، استخدم «استيراد ملفات». تُنسخ الملفات المختارة إلى تخزين المتصفح المحلي حتى يمكن تشغيلها لاحقًا دون إعادة اختيارها، ما دامت بيانات الموقع لم تُمسح وكانت المساحة كافية. عند الاستيراد سيطلب التطبيق اسمًا للكتاب/المجموعة.
4. اضغط زر التشغيل بجوار الملف. يُحفظ موضع التوقف تلقائيًا، ويظهر تقدّم الملف وتقدّم المجموعة. تقدّم المجموعة محسوب بحسب مدد الملفات المعروفة.
5. من المشغّل أضف علامات مرجعية مع اسم وملاحظة اختيارية، ثم اضغط أي علامة للانتقال إلى موضعها.
6. «تصدير نسخة احتياطية» يصدر التقدّم والعلامات والبيانات الوصفية فقط، ولا يتضمن الملفات الصوتية ولا أذونات المجلد.

## قيود وخصوصية مهمة
- لا يرفع التطبيق ملفات الصوت إلى GitHub أو إلى خادم خارجي. الملفات المستوردة تُحفظ داخل مساحة الموقع في المتصفح؛ وقد تستهلك مساحة كبيرة، لذا استورد ما تحتاجه فقط.
- خيار اختيار المجلد يعتمد على دعم المتصفح. دعم File System Access API يختلف، وقد لا يكون متاحًا على بعض هواتف Android؛ عندها استخدم استيراد الملفات.
- إذا استخدمت مرجع المجلد، فالتطبيق لا ينسخ الصوت إلى تخزينه؛ يحتاج إلى إذن القراءة للوصول إلى الملف. إذا نُقل الملف أو حُذف أو أُلغي الإذن، أعد اختيار المجلد.
- حذف بيانات الموقع أو بيانات المتصفح قد يمسح المكتبة المحلية والتقدّم والعلامات. النسخة الاحتياطية لا تشمل الصوتيات.
- تقدم المجموعة يعتمد على الملفات ذات المدة التي استطاع المشغل قراءتها؛ تظهر الملفات غير المعروفة المدة بنسبة غير محسوبة حتى تُشغّل مرة.
- هذه النسخة تحفظ العلامات ومواضع التشغيل على نفس نطاق الموقع/المتصفح، ولا تزامنها بين الأجهزة.
