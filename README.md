# صوتي — المكتبة الصوتية الإسلامية (المرحلة الأولى)

واجهة عربية RTL متجاوبة للمكتبة، مع بحث وتصنيفات وبطاقات كتب وصفحات تفاصيل ومفضلة ومظهر داكن. تحتوي هذه النسخة على بيانات تجريبية فقط؛ لا توجد ملفات صوتية فعلية بعد.

## الملفات
- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب.
- `app.js`: بيانات الكتب والبحث والتصنيفات والمفضلة والتفاصيل.
- `manifest.json`: بيانات تثبيت PWA.
- `sw.js`: تخزين أولي لملفات واجهة التطبيق فقط، وليس للكتب الصوتية.
- `assets/icon.svg`: أيقونة التطبيق.

## النشر من الهاتف
1. أنشئ مستودع GitHub باسم `sawti-islamic-library` واجعله Public.
2. ارفع محتويات هذه الحزمة إلى جذر المستودع مباشرة، بحيث يظهر `index.html` بجانب `app.js` و`styles.css`، ويكون مجلد `assets` في الجذر.
3. افتح المستودع ثم Settings → Pages.
4. من Build and deployment اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)`، واضغط Save.
5. انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages. لا تفترض أن النشر اكتمل حتى يظهر رابط الموقع وحالة ناجحة.
6. افتح الرابط عبر HTTPS. جرّب البحث، والتصنيفات، والتفاصيل، والمفضلة، والمظهر الداكن.
7. لاختبار الواجهة دون اتصال: افتح الموقع مرة مع اتصال الإنترنت وانتظر تحميله، ثم فعّل وضع الطيران وأعد فتحه. قد يتطلب أول تسجيل Service Worker إعادة تحميل واحدة.

## ملاحظات فنية
- مسارات الملفات نسبية لتعمل على رابط مشروع GitHub Pages.
- أول تسجيل لـ Service Worker يحدث عند فتح الموقع عبر HTTPS أو localhost، وليس عند فتح الملف محليًا مباشرة.
- عند تحديث ملفات الواجهة، غيّر `CACHE_NAME` في `sw.js` من `sawti-shell-v1` إلى `sawti-shell-v2` (وزد الرقم في كل إصدار جديد) لإبطال التخزين المؤقت القديم.
- هذه المرحلة لا تنفذ تشغيلًا صوتيًا أو تنزيل كتب. ستضاف هذه الوظائف في المرحلة الثانية وما بعدها بعد اختبار المصادر.
